# LABFICAT — Laboratorio de Caracterización Fisicoquímica de Alimentos

Sistema de gestión del laboratorio **LABFICAT** del Centro Agroturístico de San Gil (SENA).

- **Backend:** `BACKEND/` — Node.js + Express + MongoDB Atlas (Mongoose), arquitectura MVC, ES Modules.
- **Frontend:** `FRONTEN/` — Vue 3 + Quasar + Pinia.
- **Documentación:** `DOCUMENTACION/` — memoria, bitácora, reglas de negocio y formularios.

Consulta `DOCUMENTACION/MEMORIA_PROYECTO.md` antes de modificar el proyecto.
